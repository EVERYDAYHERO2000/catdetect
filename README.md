# CatDetect

Распознаёт кошек и собак на камерах видеорегистраторов Dahua, узнаёт конкретных животных
и определяет направление (пришёл к двери или ушёл). Состояние передаётся в Home Assistant
через собственную интеграцию.

```
Dahua NVR ──событие движения (HTTP)──▶ ┌──────────────── CatDetect (Docker) ────────────────────┐
          ──RTSP-поток────────────────▶ │ YOLO: кошка/собака → трекер → линия двери → кто это?  │
                                        │ веб-интерфейс: регистраторы, камеры, зоны, разметка,    │
                                        │ обучение                                               │
                                        └───────────────┬───────────────────────────────────────┘
                                                        │ REST + WebSocket (токен)
                                                        ▼
                                        Home Assistant ─ интеграция custom_components/catdetect
```

## Состав репозитория

| Путь | Что это |
|---|---|
| `service/` | Python-сервис (FastAPI, ultralytics YOLO26, SQLite) |
| `web/` | Веб-интерфейс (React + TypeScript), собирается в статику и отдаётся сервисом |
| `custom_components/catdetect/` | Интеграция Home Assistant (ставится через HACS или копированием) |
| `docker/` | Dockerfile и compose-файлы (CPU + OpenVINO по умолчанию; вариант для NVIDIA) |

## Данные

Сервис хранит базу, кадры и модели в каталоге данных: в Docker это том `/data`
(в `docker/compose.yml` — `C:\catdetect-data`). Необязательные переменные окружения описаны
в `service/.env.example`.

## Установка (Windows, Docker Desktop)

Сервис рассчитан на работу на процессоре: модель автоматически экспортируется в OpenVINO,
на современном 8–12-ядерном CPU (например, Ryzen AI 9 HX 370) кадр обрабатывается за ~30–60 мс.
Видеокарта не нужна.

1. Установите **Docker Desktop** (бэкенд WSL2) и включите его автозапуск.
2. Создайте папку `C:\catdetect-data`.
3. В папке проекта выполните:
   ```
   docker compose -f docker/compose.yml up -d --build
   ```
4. Откройте `http://<IP-ПК>:8000` и создайте администратора. При первом запуске скачивается и
   конвертируется модель (1–2 минуты); статус и время обработки кадра видны на странице «Обзор».
5. Отключите сон ПК (Параметры → Система → Питание): пока ПК спит, детекция не работает.
6. Разрешите входящие подключения на порт 8000 в брандмауэре Windows.

Обновление: `git pull`, затем та же команда `docker compose … up -d --build`.

На компьютере с видеокартой NVIDIA:
`docker compose -f docker/compose.yml -f docker/compose.nvidia.yml up -d --build`.

Процессор или видеокарту можно выбрать в **Настройки → Вычисления** («Автоматически» выбирает видеокарту,
если она есть: CUDA у NVIDIA, Metal у Apple). Настройка действует и на распознавание, и на обучение;
там же видно время обработки кадра.

Если процессор не успевает (время кадра больше ~150 мс при нескольких камерах), уменьшите «Кадров/сек»
в настройках камеры или используйте модель поменьше: `CATDETECT_BASE_DETECTOR=yolo26s.pt`
в `C:\catdetect-data\.env`.

## Первичная настройка (веб-интерфейс)

1. **Регистраторы → Добавить.** Укажите адрес и учётные данные регистратора. «Проверить связь» покажет
   модель и список каналов.
2. Нажмите **«Добавить камеру»** напротив нужного канала. Поток «дополнительный» (sub) обычно достаточен
   и разгружает сеть.
3. На странице камеры нарисуйте:
   - **Зону**: область, где искать животных (всё вне её игнорируется: окна соседей, дорога).
   - **Линию** поперёк пути к двери и **точку двери** на стороне двери. Пересечение линии в сторону двери —
     событие «пришёл», в обратную — «ушёл»; пока животное по ту сторону линии, где дверь, сенсор «у двери» включён.
4. **«Тест детекции на кадре»** показывает, что видит модель прямо сейчас.
   Для каждой камеры можно включить виды: **кошка, собака, человек**. Для людей работают те же
   события и сенсоры (`person_seen`, `person_arrived`, `person_left`) — удобно и для проверки автоматизаций.
5. **Объекты:** добавьте своих животных и людей («Барсик», «Рекс», «Илья») и группы («Чужие кошки», «Курьеры»).

## Разметка и обучение

Стандартная модель YOLO обучена на фото, снятых сбоку. При ракурсе сверху над дверью она ошибается чаще.
Сервис сам сохраняет кадры с найденными животными в очередь **«Разметка»**:

- поправьте рамки (пунктир — предложения модели), выберите вид и конкретное животное (`1`…`9`), нажмите `Enter`;
- ложные срабатывания отмечайте **«Нет животных»** (`N`): это тоже обучает модель;
- можно загрузить свои фото кнопкой «Загрузить фото».

На странице **«Обучение»**:

- **Детектор** дообучается на ваших кадрах. Нужно хотя бы 10 кадров с животными, хорошо — 200 и больше.
  На процессоре обучение детектора занимает от десятков минут до нескольких часов; детекция при этом продолжает работать.
- **Классификатор** учится различать ваших животных и людей. Нужно минимум 2 объекта, у каждого от 5 примеров;
  лучше 50 и больше, днём и ночью в ИК-режиме.

После обучения сравните метрики и нажмите **«Активировать»**. К базовой модели можно вернуться в любой момент.

## Home Assistant

1. Установите интеграцию одним из способов:
   - **HACS** → Custom repositories → URL git-репозитория, тип *Integration*;
   - или скопируйте папку `custom_components/catdetect` в `/config/custom_components/` (через Samba или
     File editor) и перезапустите HA.
2. В веб-интерфейсе CatDetect: **Настройки → Создать токен**.
3. В HA: **Настройки → Устройства и службы → Добавить интеграцию → CatDetect**, укажите адрес
   `http://<IP-ПК>:8000` и токен.

Что появится в HA:

| Устройство | Сущности |
|---|---|
| Камера | `binary_sensor` «Кошка», «Собака», «Кошка у двери», «Собака у двери», «Движение», «Видеопоток»; `event` «Животные» (`cat_arrived`, `cat_left`, `cat_seen`, …); `image` «Последний снимок» |
| Животное | `binary_sensor` «В кадре», «У двери»; `sensor` «Последнее направление» (пришёл/ушёл), «Последний раз замечен», «Последняя камера»; `event` «События» (`arrived`, `left`, `seen`) |

Пример автоматизации «Барсик пришёл и ждёт у двери»:

```yaml
triggers:
  - trigger: state
    entity_id: binary_sensor.barsik_u_dveri
    to: "on"
    for: "00:00:03"
actions:
  - action: notify.mobile_app_phone
    data:
      title: "Барсик у двери"
      message: "Открыть?"
      data:
        image: /api/image_proxy/image.vkhodnaia_dver_poslednii_snimok
```

(Точные `entity_id` посмотрите в HA: они зависят от названий камер и животных.)

## Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -e "service[ml,dev]"
.venv/bin/pytest service/tests
CATDETECT_DATA_DIR=./data .venv/bin/python -m catdetect --port 8765
cd web && npm install && npm run dev   # интерфейс с hot reload на :5173, API проксируется на :8765
```

Для отладки без регистратора создайте камеру с источником «Свой URL» и путём к видеофайлу:
файл проигрывается по кругу, анализ идёт постоянно.
